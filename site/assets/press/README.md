# Press outlet logos

Drop outlet logo images here as `<slug>.png` and they render automatically in the
portfolio "In the news" section (replacing the text wordmark fallback). No code
change needed — the showcase looks for `assets/press/<slug>.png` per mention.

Recommended: transparent PNG, ~44px tall (88px @2x), trimmed tight. SVG also works
if you rename the render target, but PNG is the zero-config path.
